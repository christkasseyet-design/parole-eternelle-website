# Guide d'administration du site — C.E. Parole Éternelle

Ce guide est pour la personne qui met le site à jour. **Aucune programmation
n'est nécessaire.** Tout se fait dans le panneau d'administration, avec des
formulaires.

## 1. Se connecter

1. Ouvrez **https://paroleeternelle.com/admin**
2. Cliquez sur **« Se connecter avec GitHub »**.
3. Connectez-vous avec votre compte GitHub et acceptez l'autorisation (une seule fois).

> Il faut avoir un compte GitHub gratuit **et** avoir été invité comme
> collaborateur du projet par le propriétaire du site.

## 2. Ce que vous pouvez modifier

| Menu à gauche | Formulaire | À quoi ça sert |
|---|---|---|
| **Programme** | Événements spéciaux (datés) | Une conférence, un culte spécial, une soirée… avec date et heure |
| **Programme** | Rythme de la semaine | Les rendez-vous qui reviennent chaque semaine (culte du dimanche, étude biblique…) |
| **Page d'accueil** | Bandeau « événement phare » | Le grand bandeau avec l'affiche en haut du site |
| **Page d'accueil** | Vidéo à la une | La vidéo YouTube mise en avant dans « Médias » |
| **Page d'accueil** | Reels | Les cartes verticales TikTok / Facebook / YouTube |
| **Galerie photos** | Albums et photos | Toutes les photos du site |

## 3. Les gestes de base

### Ajouter un événement au programme
1. **Programme → Événements spéciaux (datés)** → bouton **« Ajouter événement »**.
2. Remplissez : date, heure (comme `17:00`), titre, catégorie, durée, orateur.
3. Cliquez **« Publier »** (en haut) puis **« Publier maintenant »**.
4. Attendez 1 à 3 minutes, puis actualisez le site.

Astuce : si un événement tombe le même jour **et** à la même heure qu'un
rendez-vous de la semaine, il le **remplace** — utile pour donner un titre
précis à un culte (« Culte de la Sainte Cène »).

### Changer les rendez-vous qui reviennent chaque semaine
**Programme → Rythme de la semaine** : modifiez ou ajoutez une ligne
(jour, heure, titre). Ils apparaissent automatiquement dans tous les mois.

### Ajouter des photos
1. **Galerie photos → Albums et photos**, ouvrez l'album voulu.
2. Dans « Photos », cliquez **« Ajouter photo »**, puis **« Choisir une image »**
   et envoyez la photo depuis le téléphone ou l'ordinateur.
3. Écrivez une légende courte → **Publier**.

**Conseil important :** les connexions à Kinshasa sont lentes. Avant d'envoyer
une photo, réduisez-la (idéalement **moins de 500 Ko**, largeur 1600 px). Une
photo de 5 Mo ralentit tout le site pour les visiteurs.

### Ajouter une vidéo
Les vidéos ne sont **pas** envoyées sur le site (trop lourdes). On les publie
d'abord sur **YouTube** (ou TikTok / Facebook), puis :
- **Vidéo à la une** : collez le lien YouTube, titre, prédicateur.
- **Reels** : ajoutez une carte avec image de couverture + lien de la vidéo.
- Les prédications de la chaîne YouTube apparaissent **toutes seules** dans la
  section Médias — rien à faire.

### Cacher ou remplacer le grand bandeau
**Page d'accueil → Bandeau « événement phare »** : décochez
**« Afficher ce bandeau sur le site »** pour le cacher, ou changez le titre,
l'affiche et les boutons pour annoncer le prochain événement.

## 4. Si quelque chose ne va pas
- **Le site ne change pas** : attendez 3 minutes, puis actualisez en
  maintenant la touche Ctrl (ou Maj) enfoncée.
- **J'ai fait une erreur** : rouvrez le formulaire, corrigez, publiez à nouveau.
  Rien n'est jamais perdu : chaque modification est conservée dans l'historique
  du projet et peut être annulée par le propriétaire.
- **Le panneau ne s'ouvre pas** : vérifiez la connexion internet, puis
  reconnectez-vous. Si le problème continue, prévenez le propriétaire du site.

## 5. Ce que le panneau ne modifie pas (encore)
Les textes longs (À propos, Ministères, Contact, Dons), le design et les
couleurs ne sont pas modifiables depuis ce panneau — ils demandent une
intervention technique (voir `REMISE.md`).
